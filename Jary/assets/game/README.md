# Jary/assets/game/

《JARY 逃离奶龙》的立绘。现在放的是真图。

| 文件 | 画面上的角色 | 现用尺寸 |
| --- | --- | --- |
| `jary.png` | JARY（骑共享单车，朝右） | 225 × 384 |
| `nailong.png` | 追上来的奶龙（朝右） | 268 × 352 |
| `laugh.png` | 被追上时成绩卡上的奶龙（捧腹大笑） | 273 × 520 |

前两张的素材是 704 × 1504 与 896 × 1184 的透明底 PNG，
按内容裁掉四周透明边再缩放，两张合计约 200 KB。

`laugh.png` 的原图是白底（399 × 678，没有透明通道）。成绩卡本身就是白的，
所以没抠图，只把地面那层浅灰投影压成纯白、再裁掉四周留白：
「色差 ≤ 22 且最暗通道 ≥ 185」的像素一律填白，然后按内容重新裁边。
换图时照这个思路处理即可，直接放一张带白底的图也不会露馅。

## 怎么挂上去

`Jary/escape-nailong.html` 的 canvas 上已经写好了：

```html
<canvas id="nailong-canvas" class="game-canvas" width="960" height="420" tabindex="0"
        data-jary-sprite="assets/game/jary.png"
        data-nailong-sprite="assets/game/nailong.png"
        data-laugh-sprite="assets/game/laugh.png"
        aria-label="JARY 逃离奶龙 游戏画面 / JARY Escapes Nailong game canvas"></canvas>
```

- **换画风**：把同名文件替换掉就行，路径不用改。
- **删掉这几个属性**：退回模块里现画的卡通角色，页面不会发出任何图片请求。
- **路径写错**：控制台留一行提示，画面自动退回内置角色 / 纯文字成绩卡，不会出现裂图。

## 摆放规则

- 立绘按**原始长宽比**缩放到目标高度，不会被拉变形：
  - JARY 站姿按 104 逻辑 px 高绘制，滑铲时整体压到 62（是缩小，不是压扁），最宽 170；
  - 奶龙按 96 逻辑 px 高绘制，最宽 190；
  - 成绩卡上的奶龙按 264 逻辑 px 高绘制，最宽 176。
  - 所以新图只要**裁干净、比例正常**即可，不必凑某个固定尺寸。
- **透明底的 PNG 效果最好**：带背景的图会看到一个圆角方块。
- 单张控制在 200 KB 以内——三张都是进游戏就加载的。

## 声音

| 文件 | 用在哪 | 时长 | 大小 |
| --- | --- | --- | --- |
| `theme.m4a` | 开局起循环播放的配乐（《苦行东南山》） | 3:02 | 4.5 MB |
| `laugh.m4a` | 被奶龙追上时的笑声，从头放到尾 | 0:19 | 377 KB |

小红花的提示音不在这里——它是 Web Audio 现场合成的一小段双音，不额外占文件。

页面上那排按钮的「静音」是开关：静音时配乐、笑声、提示音全部不响，
选择记在 `localStorage` 的 `jary-nailong-sound` 里（写 `off` 表示静音，其余都当有声），
下次进来沿用。浏览器不允许页面自己在没交互时出声，所以音频元素是在
**第一次点按钮或按键时**才创建的，在此之前不会向服务器要这两个文件。

- **换曲子**：替换同名文件即可。
- `theme.m4a` 有 4.5 MB，是整首原曲，第一次开局会等一会儿才响；
  想让它轻一点得先用 ffmpeg 之类重新压一遍（本机没装，所以保持原样）。
