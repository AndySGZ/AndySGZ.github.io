# 动态栏目的配图放这里

往这个目录丢图片，然后在 `updates-data.js` 里写路径。路径**从 `Jary/` 目录写起**：

```js
{
  date: '2026-09-22',
  title: { zh: '题目', en: 'Title' },
  text: '正文。',
  images: [
    { src: 'assets/updates/我的截图.png', alt: '一句话说明', caption: { zh: '图注', en: 'Caption' } }
  ]
}
```

- `images` 留空或整条不写 → 这条动态就是纯文字，版式不会塌。
- 一张图铺满整行；**两张以上并排**，窄屏自动落回一张一行。
- 图挂了（路径写错、文件没传）时页面上留一个安静的空框，不显示裂图，
  同时在浏览器控制台报一句 `[updates] 图片加载失败：...`，照着路径找问题就行。

## 尺寸

**长边 1200px** 就够（页面上最宽也就 1100 多 px，三张并排时每张才 350px 上下）。
截图优先用 WebP 或 PNG，照片用 **WebP q82**，单张压在 **300 KB 以内**。
GitHub Pages 不做图片压缩，图多大访客就得下多大。

手机拍的竖图不用先裁成横的：页面上图片是按原始比例走的，不会拉变形。
只是竖图并排时会很高（三张 3:4 的并排，一屏基本就占满了），
要是嫌太高，要么少放两张，要么出图时先裁一裁。

手机照片记得**按 EXIF 摆正**再转（PIL 里就是 `ImageOps.exif_transpose`）：
浏览器认 EXIF 所以本地看着是正的，一旦转码丢掉 EXIF 就会躺倒。
