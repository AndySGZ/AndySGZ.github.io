# 动态栏目的配图放这里

往这个目录丢图片，然后在 `updates-data.js` 里写路径。路径**从 `Jary/` 目录写起**：

```js
{
  date: '2026-09-22',
  title: { zh: '题目', en: 'Title' },
  text: '正文。',
  images: [
    { src: 'assets/updates/我的截图.png', alt: '一句话说明', caption: { zh: '图注', en: 'Caption' } }
  ]
}
```

- `images` 留空或整条不写 → 这条动态就是纯文字，版式不会塌。
- 一张图铺满整行；**两张以上并排**，窄屏自动落回一张一行。
- 图挂了（路径写错、文件没传）时页面上留一个安静的空框，不显示裂图，
  同时在浏览器控制台报一句 `[updates] 图片加载失败：...`，照着路径找问题就行。

## 尺寸

按 16:9 或更宽出图，**宽 1200px 左右**就够（页面上最宽也就 1100 多 px）。
截图优先用 **WebP** 或 PNG，照片用 JPG，单张压在 **300 KB 以内**。
GitHub Pages 不做图片压缩，图多大访客就得下多大。
