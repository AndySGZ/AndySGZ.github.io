# 石广喆个人主页设计

## 目标

制作一个单屏个人主页，以“石广喆”的名字和一把小提琴为唯一核心内容。页面需要同时融合霓虹舞台、梦幻极光与华丽古典剧院三种气质，在桌面和手机上都保持强烈但清晰的视觉焦点。

## 视觉结构

- 深黑舞台作为底层，使用细微噪点、暗红渐晕和地面反光营造空间。
- 左右两侧使用暗红丝绒幕布与克制的金色饰边，构成古典剧院框架，但不遮挡中央内容。
- 中央上方展示超大“石广喆”文字，采用持续流动的多色渐变、辉光和轻微悬浮效果。
- 名字下方展示一把独立、写实、鎏金且带霓虹轮廓的小提琴；它是页面的第二视觉焦点。
- 极光光带、星屑、聚光灯和舞台倒影负责连接文字与小提琴，避免视觉元素彼此割裂。

## 动画与交互

- 页面载入时，幕布、名字与小提琴依次淡入，不出现长时间等待或加载界面。
- 名字的虹彩缓慢横向流动，辉光轻微呼吸；小提琴做幅度很小的悬浮与光泽扫过动画。
- 鼠标移动时，背景光晕、名字和小提琴以不同幅度产生轻微视差。
- 点击或轻触小提琴时，以琴身为中心扩散彩色音浪，并短暂增强星屑和辉光。
- 尊重 `prefers-reduced-motion`：关闭持续位移、视差和强烈扩散动画，仅保留静态视觉。

## 技术方案

- 页面实现为根目录下的单个 `index.html`，CSS 与 JavaScript 内联，便于 GitHub Pages 直接发布。
- 小提琴使用项目内的透明背景 PNG 素材，不依赖外部图片服务。
- 幕布、聚光灯、极光、粒子与音浪通过 CSS 和少量原生 JavaScript 实现，不引入框架或第三方依赖。
- JavaScript 只负责指针视差、音浪触发和轻量粒子响应；页面在脚本不可用时仍能完整展示核心内容。

## 响应式与可访问性

- 内容在常见桌面与手机视口内完整可见，不允许名字、小提琴或幕布互相遮挡。
- 名字采用断点与容器约束控制尺寸，不使用纯视口宽度缩放字体。
- 小提琴保持稳定纵横比，并在窄屏中缩小而不裁切。
- 小提琴交互区域可用键盘聚焦，并支持 Enter/Space 触发音浪；页面提供明确的中文标题和替代文本。

## 验收标准

- 首屏能清楚看到“石广喆”与完整小提琴，两者层级明确。
- 三种风格均有可辨识表现，但整体不显杂乱。
- 桌面与手机截图中无文本溢出、内容遮挡、横向滚动或素材加载失败。
- 点击、轻触和键盘均能触发音浪；减少动态效果偏好生效。
- 页面无需构建步骤，可直接由静态服务器或 GitHub Pages 访问。
