# 练琴页配图放这里

把图片文件直接丢进这个文件夹（`assets/practice/`），然后在
`scripts/site-data.js` 的 `practice` 里写路径。

## 怎么引用

路径**从站点根目录写起**，不带开头的斜杠：

```js
practice: {
  // 页头右侧的方形图
  intro: { image: 'assets/practice/intro.jpg', alt: '练琴' },

  stages: [
    { stage: '在练', items: [
      {
        title: '无伴奏小提琴奏鸣曲第一号 · 柔板',
        composer: 'J. S. 巴赫',
        note: '每天先过一遍音准，再谈表情。',
        image: 'assets/practice/bach-bwv1001.jpg',   // ← 曲目右侧的横向图
        alt: '柔板开头的主题谱例'
      }
    ]}
  ]
}
```

`image` 留空（`''`）时，页面上会显示一个空的占位框，版式不会塌。

## 文件命名

**用纯英文小写 + 连字符，不要用中文文件名。**

- 推荐：`bach-bwv1001-adagio.jpg`
- 避免：`巴赫柔板.jpg`

中文文件名在网址里会被转成 `%E5%B7%B4%E8%B5%AB...` 这种百分号编码，
又长又难认，手打和分享都容易出错。

## 尺寸建议

| 位置 | 比例 | 建议导出尺寸 |
| --- | --- | --- |
| 曲目右侧（横向） | 16 : 9 | 1200 × 675 |
| 页头右侧（方形） | 1 : 1 | 800 × 800 |

## 体积

单张控制在 **300 KB 以内**。

谱例截图优先用 **WebP**：线条锐利、体积比 PNG 小很多。
照片可以用 JPG。原图别直接扔进来，先压一下——
GitHub Pages 没有图片压缩，图多大用户就得下多大。

## 显示方式（不用改，知道就行）

- **曲目图** 用 `object-fit: contain`：**不裁剪**。谱例不会被切掉音符，
  比例和 16:9 不符时上下或左右留白。留白用的是页面底色，所以这两种情况下
  都看不出来：浅色主题下和白纸、深色主题下和黑底各自融在一起。
- **页头方图** 用 `object-fit: cover`：**填满并居中裁剪**，适合照片。
